# bilibili-unfollow-helper <br>(B站关注列表标签分析 & 批量取关)
# ZH :<br>
按需分析选中的UP主最新视频标签，展示个人简介，支持全选/反选及批量取关<br>
此为用户脚本，需使用tampermonkey等脚本管理器进行安装。<br>
受限于b站api防刷限制，在极端情况可能获取无数据，一般选中重试可解决
# EN: <br>
This script analyzes the latest video tags of selected content creators (UPs) on demand, displays their personal profiles, and supports selecting all/deselecting and batch unfollowing.<br>
This is a user-defined script and requires a script manager such as Tampermonkey for installation.<br>
Due to Bilibili's API anti-fraud restrictions, in extreme cases, no data may be retrieved. Selecting "retry" usually resolves this.<br>
